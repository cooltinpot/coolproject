# coolproject — Minecraft.js

A Minecraft clone that runs in the browser, written in plain JavaScript with [three.js](https://threejs.org/).
It has no build step and loads no asset files: every texture, icon, mob skin and sound is generated by code
when the page starts.

## Running it

ES modules need to be served over HTTP, so opening `index.html` straight from disk won't work. From the repo root, run:

```sh
python3 -m http.server 8000
# or: npx serve .
```

Then open <http://localhost:8000>. The game needs a browser with WebGL2 (any recent Chrome, Firefox, Edge or Safari).
three.js is vendored in `vendor/`, so the game also runs offline. Only the pixel font comes from Google Fonts, and the game falls back to a system monospace font without it.

## Features

**World**
- Infinite terrain built from 16×16×128 chunks, streamed in and out around the player with an adjustable render distance
- Seeded generation using simplex noise for continents, mountains, and spaghetti and cheese caves (with lava lakes deep down)
- 8 biomes: Plains, Forest, Desert, Snowy Tundra, Mountains, Beach, Ocean and Frozen Ocean
- Oak, birch and spruce trees, cacti, flowers, tall grass, pumpkins and dead bushes
- Coal, iron, gold, redstone and diamond ores, plus gravel and dirt pockets
- Dungeons: mossy cobblestone rooms with cobwebs and loot chests
- **The Nether**:
  - Build an obsidian frame and light it with flint and steel to make a portal
  - Stand inside the portal to travel. One block in the Nether is eight in the overworld, and the game links to an existing portal or builds a new one
  - Netherrack caverns with a lava sea, glowstone, soul sand, quartz ore and neutral zombie pigmen
  - The Nether is saved separately from the overworld
- 60+ block types and 100+ items

**Rendering**
- Flood-fill sky light and block light (levels 0–15, like Minecraft) with smooth lighting and ambient occlusion
- Day/night cycle (20 minutes per day) with sun, moon, stars, sunsets and scrolling clouds
- Translucent water with sloped surfaces, glowing lava, cutout leaves and glass
- Distance fog, plus underwater and in-lava fog
- Particles for block breaking, explosions, smoke, torch flames and bubbles
- First-person held item and arm with swing and bobbing; F5 switches to third person

**Gameplay**
- Survival and Creative modes. Creative adds flying (double-tap Space), instant breaking and a searchable item palette
- Block breaking speed depends on the tool, its material tier and the block's hardness; some blocks need a minimum tier to drop
- Health, hunger, saturation, natural regeneration, fall damage, drowning, lava, fire and cactus damage
- 2×2 and 3×3 crafting with about 50 recipes, including all wood, stone, iron, gold and diamond tools
- Furnaces with fuel and smelting (ores, sand to glass, cooking food, charcoal, bricks)
- Chests (dungeon loot or player-placed), beds (skip the night and set the spawn point), ladders, torches and TNT
- Slabs (stackable into double slabs), stairs (including upside-down), and doors that open and close
- Step-up movement, so you can walk onto slabs and stairs without jumping, like in Minecraft
- Armor in leather, gold, iron and diamond. It has its own slots, an armor bar, damage reduction and durability
- Bows with charge-up and zoom, and arrows you can pick back up
- Redstone:
  - Dust carries a signal that weakens by one level per block, and can step up and down blocks
  - Power sources: levers, buttons and pressure plates
  - Redstone torches act as inverters
  - Lamps, doors and TNT respond to power
- Weather: rain, snow in cold biomes, and thunderstorms with lightning. Rain puts out fires and stops undead burning in daylight
- Flowing water and lava. Water meeting lava makes obsidian or cobblestone. Buckets pick up and place fluids
- Falling sand and gravel, leaf decay, saplings that grow into trees, grass spreading, cactus growth and ice melting
- Farming: till dirt with a hoe, plant seeds, wheat grows in stages, craft bread. Bone meal makes crops and saplings grow
- Mobs:
  - Passive: pigs, cows, sheep and chickens (breed them with wheat or seeds)
  - Hostile: zombies and skeletons (which burn in daylight; skeletons keep their distance and shoot arrows), creepers (which explode) and spiders (which climb walls)
- Mob drops, XP and levels, critical hits, knockback and tool durability
- Death screen, item drop on death and respawn
- Chat and commands
- Autosave to `localStorage`, multiple worlds, and chunk data stored deflate-compressed

## Controls

| Key | Action |
| --- | --- |
| WASD | Move |
| Space | Jump / swim / fly up |
| Shift | Sneak (stops you falling off edges) / fly down |
| Ctrl or R | Sprint |
| Left click | Mine / attack |
| Right click | Place / use / eat (hold) |
| Middle click | Pick block |
| 1–9, mouse wheel | Hotbar |
| E | Inventory |
| Q / Ctrl+Q | Drop item / stack |
| T, / | Chat / command |
| F1 / F3 / F5 | Hide HUD / debug info / camera view |
| Esc | Pause |

**Inventory:**
- Left click picks up or places a stack.
- Right click picks up half a stack, or places one item.
- Shift-click moves a stack between sections.
- Number keys swap the hovered slot with that hotbar slot.

## Commands

`/help`, `/gamemode <survival|creative>`, `/time set <day|noon|night|midnight|ticks>`, `/give <item> [count]`,
`/tp <x> <y> <z>` (supports `~`), `/summon <pig|cow|sheep|chicken|zombie|skeleton|creeper|spider>`, `/weather <clear|rain|thunder>`, `/dimension <overworld|nether>`, `/kill`, `/heal`, `/seed`,
`/spawnpoint`, `/clear`, `/fly`, `/locate`

## Code layout

```
index.html, style.css     page shell, HUD and menus
src/main.js               bootstrap and wiring
src/game.js               game loop, interaction, combat, explosions, rendering, commands
src/blocks.js             block and item registry, tool and harvest rules
src/textures.js           procedural pixel-art textures → WebGL2 texture array + item icons
src/inventory.js          item stacks, crafting recipes, smelting, loot
src/world/
  chunk.js                chunk storage
  generator.js            terrain, biomes, caves, ores, trees, dungeons
  lighting.js             sky and block light flood fill (add and remove)
  mesher.js               chunk meshing, smooth lighting / AO, special shapes, fluids
  world.js                chunk streaming, block updates, fluids, random ticks, raycasting
  redstone.js             redstone power: dust, sources, torches, consumers
src/entities/
  physics.js              AABB versus voxel collision
  player.js               movement, survival stats
  mobs.js, models.js      mob AI, spawning and box models
  items.js                dropped items, falling blocks, primed TNT, particles
src/render/               chunk shaders, sky
src/ui/                   HUD, menus, inventory and container screens
src/audio.js              procedural WebAudio sound effects and ambient music
src/save.js               localStorage persistence
```

## Not included

This is a large slice of Minecraft, not all of it. The following aren't implemented:
- The End
- Repeaters, comparators and pistons (the rest of redstone)
- Villages
- Enchanting and potions
- Multiplayer
